---
title: "API keys"
description: "Read your analytics from your own code, scripts and dashboards."
weight: 9
---

1. Open **API Keys** in the sidebar.
2. Choose **Create API Key**.
3. Give it a **Key Name** that says where it's used (for example "Weekly KPI script").
4. Pick its **Permissions**: **Read**, **Write** and/or **Admin**. Give each key only what it needs; most scripts need **Read** only.
5. Choose **Create Key**, and copy the key somewhere safe.

![Creating an API key](/images/help/api-key.jpg)

Treat a key like a password. If one leaks or you stop using it, choose **Revoke** next to it; anything using that key stops working immediately.

What you can do with a key: see the [API reference](/docs/api/).
